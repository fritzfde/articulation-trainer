# Articulate — Daily Communication Trainer

A mobile-first PWA for a 5-minute daily communication workout: say-this-not-that upgrades, scenario quizzes, a 60-second impromptu speaking arena with live transcript & filler detection, and vocal warm-ups.

Plain HTML/CSS/JS — no build step. All progress is stored in `localStorage` on your device.

Open on iPhone in Safari → Share → **Add to Home Screen**.
